# Model registry for the llm plugin (:help llm-models).
#
# Weights are not tracked. :LlmDownload {name} fetches a file from
# https://huggingface.co/{repo}/resolve/main/{file} into this directory;
# the plugin also finds files already downloaded by llama.cpp itself
# (llama-server -hf ...) in its cache directory.
#
# Q8_0 and Q4_K_M entries both appear below. Measurements on the AMD machine
# put them level: on 99 completions from this repo the 7B answered identically
# at both quantizations, while Q4_K_M is half the size and 55% faster. Prefer
# the -q4 rows unless something here is shown to need the extra precision.
#
# Which row to use depends on the card, and on a laptop also on the power mode.
# See BENCHMARKS.md in this directory; a machine's own pick lives in
# after/plugin/local.vim.
#
# name                repo                                     file                            fim  notes

qwen2.5-coder-3b      ggml-org/Qwen2.5-Coder-3B-Q8_0-GGUF     qwen2.5-coder-3b-q8_0.gguf     yes  3.3 GB. Plugin default, and the laptop pick on AC: within noise of the 7B at half the wait.
qwen2.5-coder-7b      ggml-org/Qwen2.5-Coder-7B-Q8_0-GGUF     qwen2.5-coder-7b-q8_0.gguf     yes  8.1 GB. Same answers as the -q4 row below at 64% of its speed. Will not load on a 6 GB card.
qwen2.5-coder-7b-q4   QuantFactory/Qwen2.5-Coder-7B-GGUF      Qwen2.5-Coder-7B.Q4_K_M.gguf   yes  4.7 GB. Best for code: 42% exact, 116 tok/s on the AMD machine. Fits a 6 GB laptop with 235 MiB spare.
qwen2.5-coder-14b-q4  bartowski/Qwen2.5-Coder-14B-GGUF        Qwen2.5-Coder-14B-Q4_K_M.gguf  yes  9.0 GB. Best domain knowledge: 7/8 geophysics facts against 2/8 for the 7B. Needs 12 GB or more.
qwen2.5-coder-14b     ggml-org/Qwen2.5-Coder-14B-Q8_0-GGUF    qwen2.5-coder-14b-q8_0.gguf    yes  16 GB. Does not fit a 16 GB card once context is added; use the -q4 row instead.
qwen3-4b              ggml-org/Qwen3-4B-GGUF                  Qwen3-4B-Q8_0.gguf              no   4.3 GB. General model for prose; no fill-in-the-middle, so the text after the cursor is ignored. Tested worse than the coders even on prose.
